# Anduril 4 Flight Computer
**Project Charter:** [[[UVR-CH-068] Flight Computer Project Charter]](https://docs.google.com/document/d/1PksAvCCPt7eP-2tlsQyjIq21KkHghG1seeA3lu4UV-o/edit).

## Hardware
Hardware designed in KiCAD. If any footprints are added create a folder with the component name in the component-library folder and export all the files to there. When importing footprints and symbols add them to the A4-Flight-Computer library in KiCAD. Also add any datasheet and relevent documentation to this folder.

## Software
Software is an STM32CubeMX/STM32CubeIDE project using FreeRTOS.
[[Get STM32 software development tools]](https://www.st.com/en/development-tools/stm32-software-development-tools.html)
